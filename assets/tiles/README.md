# Tile artwork

Tambahkan gambar PNG untuk petak papan sesuai nama file di `ASSETS.md`. Game akan menampilkan gambar transparan/ilustrasi di setiap petak dan otomatis kembali ke icon jika file belum tersedia.

Rekomendasi: 512×512 PNG transparan atau square art dengan objek utama di tengah. Tidak perlu teks kecil karena nama petak tetap dirender oleh game.
